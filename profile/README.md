O **Instituto Felipe Hurtado (IFH)** é uma instituição de educação médica fundada pelo Dr. Felipe Hurtado. Nossa meta é levar formação de alto nível a **1 milhão de médicos** nos próximos anos.

Este é o espaço de tecnologia do Instituto.

### O que publicamos aqui

- **Projetos abertos para médicos**: ferramentas e materiais de código aberto que qualquer médico pode usar, adaptar e compartilhar. Os primeiros projetos chegam em breve.
- **Tecnologia do Instituto**: os sistemas e as páginas dos nossos programas. Esses repositórios são privados.

### Como participar

Usa um dos nossos projetos abertos e encontrou um erro, ou tem uma ideia? Abra uma *issue* no repositório do projeto.

Parcerias e outros assuntos: [contato@institutofelipehurtado.com.br](mailto:contato@institutofelipehurtado.com.br)
